# OS-01-Windows-Installation

## Experiment 1: Installation of Windows Operating System

### Aim

To install the Windows Operating System on a computer using bootable installation media and verify its successful operation.

### Procedure

1. Create a bootable Windows installation USB.
2. Configure the BIOS/UEFI boot settings.
3. Boot the system using the bootable USB.
4. Select the required language, time and keyboard settings.
5. Install Windows on the selected partition.
6. Configure the user account and system settings.
7. Verify the Windows installation using system commands.

### Verification Commands

```cmd
winver
systeminfo
hostname
diskpart
list disk
slmgr /xpr
ipconfig
